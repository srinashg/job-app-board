# job-app-board
User uploads resume/CV > system presents user with 5 relevant jobs > user must apply to all 5 jobs before receiving the next set of jobs (gamifying job applying)
The 5 jobs will be fetched from legitimate companies from their respective career sites - maybe an AI agent will fetch the jobs?
Users will earn points for every job they apply, which they can redeem for cash (this feature may be restricted due to laws)
Each job will have an application status that users can mark as 'Todo', 'Applied', 'Interview', 'Offer'
